# Валидатор тестовых данных (QA mini-tool)

## Что делает

Проверяет корректность данных, которые QA-инженер
часто вводит вручную: email, пароль, возраст.
Выдаёт отчёт PASS/FAIL по каждому полю.

## Как запустить

1. Установи Python 3.10+ (используется синтаксис tuple\[bool, str]).
2. Скопируй файл validator.py.
3. В терминале:
python validator.py
4. Введи данные по подсказкам.

## Поведение на пустом и некорректном вводе

* Пустое поле → FAIL с сообщением "поле пустое".
* Неверный формат → FAIL с указанием причины.
* Не число в возрасте → FAIL "не число".
* Программа не падает: ошибки обрабатываются внутри функций.

## Проверяемые правила

|Поле|Правило|
|-|-|
|email|есть @, есть точка в домене, без краёв|
|пароль|≥ 8 символов, минимум одна цифра|
|возраст|целое число от 18 до 99|

## Структура

* get\_input — безопасный ввод
* validate\_email / validate\_password / validate\_age — проверки
* build\_report — сборка отчёта
* main — точка входа
